Get started

Your engine, in view.

Build the image, mount the Docker socket and your repository, then open Dockyard on localhost.

docker run --rm --name dockyard -p 127.0.0.1:41739:41739 -v /var/run/docker.sock:/var/run/docker.sock -v "$PWD:/workspace:ro" dockyard
Build locally first with docker build -t dockyard .
