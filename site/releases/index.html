Image tags and changelog

Every release is published as a multi-arch container image (amd64 and arm64) on ghcr.io/piyushdoorwar/dockyard. Use latest to stay current, or pin a version tag such as 1.2.3, 1.2 or 1 for a reproducible setup.

Run the latest image

Start it from the repository you want mapped, then open http://localhost:41739.

$ docker run -d --name dockyard --restart unless-stopped -p 127.0.0.1:41739:41739 -v /var/run/docker.sock:/var/run/docker.sock -v "$PWD:/workspace:ro" ghcr.io/piyushdoorwar/dockyard:latest

Update an existing container

Pull the new image, remove the old container and run the command again. Dockyard keeps no state of its own, so nothing is lost.

$ docker pull ghcr.io/piyushdoorwar/dockyard:latest
$ docker rm -f dockyard
